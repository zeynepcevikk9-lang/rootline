# Roadmap

## Phase 0 — foundation

- Product vision and threat model.
- Typed tool contract.
- Conversation and request model.
- Deterministic mock connector.
- End-to-end plan generation without production access.

## Phase 1 — first useful workflow

- Kubernetes read connector. (started)
- Git/Gitea read connector.
- Argo CD read connector.
- Prometheus read connector.
- Evidence-backed incident investigation.
- CLI interface.
- Web planning interface. (started)

## Phase 2 — operational memory

- Service and asset catalog.
- Runbook/document ingestion.
- Incident history.
- Search with source citations.
- Team and ownership metadata.

## Phase 3 — safe execution

- Approval policies.
- Typed write actions.
- Verification steps.
- Audit trail.
- Telegram and Slack interfaces.

## Phase 4 — skill packs

- Kubernetes/GitOps.
- Linux and system administration.
- Network and DNS.
- Security operations.
- Backup and database operations.
